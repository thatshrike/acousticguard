# AcousticGuard model contract

The production APK must package a calibrated, on-device TensorFlow Lite model as
`distress_multilingual.tflite` next to this file. The binary is not generated by
Gradle because a safety detector must be trained, evaluated, and signed from a
controlled dataset before release.

Required tensor contract:

- Input tensor 0: `FLOAT32`, `INT8`, or `UINT8`, mono PCM samples represented by
  the tensor's runtime quantization scale/zero-point. FLOAT32 uses `[-1, 1]`.
- Input element count: any fixed count; the adapter right-aligns the last samples
  from the 3.5-second ring and zero-pads shorter input.
- Output tensor 0: `FLOAT32`, `INT8`, or `UINT8`, one calibrated probability per
  line in `distress_multilingual_labels.txt`, in exactly that order. Quantized
  outputs are dequantized using the tensor's runtime scale/zero-point.
- Scores must be finite calibrated probabilities in `[0, 1]`, not logits. A
  malformed tensor or invalid score fails closed.

The runtime attempts NNAPI when available and falls back to a two-thread CPU
interpreter. Full-integer quantization must be calibrated on representative
microphones and noise before the `0.82` threshold is considered valid.

The labels intentionally include English, Hindi, and transliterated Hindi help
keywords. Add language-specific labels only when the corresponding keyword-
spotting evaluation set demonstrates an acceptable false-accept rate. YAMNet
alone is not sufficient for spoken-word recognition; use a separate multilingual
keyword head or a model trained with YAMNet-style acoustic features.

## Optional owner voice embedding contract

The optional owner voice profile uses a separate asset named
`owner_voice_embedding.tflite`. The binary is intentionally not checked in or
generated by Gradle. It must be trained and evaluated as a speaker-embedding
model from consented data before being placed in an APK.

- Input tensor 0: `FLOAT32`, `INT8`, or `UINT8` mono PCM. The adapter right-aligns
  the latest samples and zero-pads shorter input.
- Output tensor 0: `FLOAT32`, `INT8`, or `UINT8` finite embedding values. The
  runtime bounds the output to 4,096 values and normalizes it before storage.
- The app stores only encrypted normalized embeddings and three scalar acoustic
  statistics. It never persists owner enrollment PCM.
- The profile is used only as a benign-speech suppression signal. A matching
  owner voice must never override explicit distress, strong non-verbal distress,
  impact plus concurrent motion, or duress.
- Missing assets, malformed tensors, invalid scores, and inference failures
  disable owner matching rather than weakening the distress detector.
