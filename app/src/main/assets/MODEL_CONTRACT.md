# AcousticGuard model contract

The production APK must package a calibrated, on-device TensorFlow Lite model as
`distress_multilingual.tflite` next to this file. The binary is not generated by
Gradle because a safety detector must be trained, evaluated, and signed from a
controlled dataset before release.

Required tensor contract:

- Input tensor 0: `FLOAT32`, mono PCM samples normalized to `[-1, 1]`.
- Input element count: any fixed count; the adapter right-aligns the last samples
  from the 3.5-second ring and zero-pads shorter input.
- Output tensor 0: `FLOAT32`, one score per line in
  `distress_multilingual_labels.txt`, in exactly that order.
- Scores must be calibrated probabilities, not logits.

The labels intentionally include English, Hindi, and transliterated Hindi help
keywords. Add language-specific labels only when the corresponding keyword-
spotting evaluation set demonstrates an acceptable false-accept rate. YAMNet
alone is not sufficient for spoken-word recognition; use a separate multilingual
keyword head or a model trained with YAMNet-style acoustic features.
